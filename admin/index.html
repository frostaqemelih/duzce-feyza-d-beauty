Siteye Giriş

Bu panel değişikliklerinizi doğrudan web sitenizin GitHub deposuna kaydeder. Devam etmek için, aşağıdaki adımlarla yalnızca bu siteye özel, yazma izinli bir GitHub erişim anahtarı (token) oluşturmanız gerekiyor.

  1. GitHub → Fine-grained token oluştur sayfasını açın.
  2. "Resource owner": frostaqemelih, "Repository access" → Only select repositories → duzce-feyza-d-beauty seçin.
  3. "Repository permissions" içinde Contents iznini Read and write yapın. Başka hiçbir izin gerekmez.
  4. Token'ı oluşturup kopyalayın ve aşağıya yapıştırın.

Bu anahtar yalnızca tarayıcınızın hafızasında (localStorage) saklanır ve yalnızca GitHub'ın kendi sunucusuna (api.github.com) gönderilir — başka hiçbir yere iletilmez. Yine de bu anahtarı kimseyle paylaşmayın; bilgisayarınızı başkasıyla paylaşıyorsanız işiniz bitince "Çıkış Yap" ile anahtarı temizleyin.
